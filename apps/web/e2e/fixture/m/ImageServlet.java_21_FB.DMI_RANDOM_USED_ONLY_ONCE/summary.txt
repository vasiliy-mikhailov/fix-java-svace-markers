FB.DMI_RANDOM_USED_ONLY_ONCE was dismissed as a false positive because the Random instance is a static field initializer evaluated once at class load, not repeatedly instantiated.

The SpotBugs checker flagged a Random instance as being created and used only once, which it warns wastes generator state and can produce predictable sequences when seeded. No test was executed because the code uses a static final field initializer that runs exactly once at class load time, eliminating the repeated-instantiation pattern the checker targets. The Random is also unseeded, using the default system seed rather than a predictable value. The finding was classified as a false positive because the PINCODE value serves as a steganography puzzle answer embedded in an image, not a security token, and the static initialization pattern structurally avoids the vulnerability the checker warns about.
